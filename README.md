# NEXORA 3D — Future Technology Experience

A futuristic, responsive 3D web experience built as part of the ALGORYX Frontend Developer Internship — Week 3 task.

## Features

- Responsive navigation with a mobile menu
- Futuristic hero section and visual effects
- Interactive 3D model viewer
- Technology feature cards
- Vision and showcase sections
- Responsive layouts for desktop and mobile
- Smooth scrolling and hover transitions

## Technologies

- React
- Vite
- JavaScript
- Three.js
- React Three Fiber
- React Three Drei
- Lucide React
- CSS3

## Getting Started

### Prerequisites

Install Node.js and npm.

### Installation

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Create a production build

```bash
npm run build
```

## 3D Model

The application loads the model from:

`public/models/iron-man.glb`

Verify the model's source and usage permissions before publishing. For the internship submission, ensure it satisfies the requirement to use an asset from Algoryx Community.
